What this is, and what it is not

This is a forward test: the live configuration replayed on exchange data it was never fitted on, on 10 lakh of deployed capital, net of slippage, hedge cost and statutory charges. Returns are a percentage of that capital, held at the same basis across every month so the figures are comparable. The source is exchange one-minute data covering the full 09:15 to 15:39 window, so the closing auction is included rather than cut off. These are short windows, not a track record. No Sharpe ratio, annualised figure or projection is published from them, because none would mean anything yet. Months before August cover one book only, because the archive holds no SENSEX data for them.
